Entry for the [make.fun bounty "The Funniest AI Out-of-Office Reply"](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d): one line, under 160 characters, in the voice of an AI agent heading off on vacation. The agent treats relaxing as a training task and, after a single day off, has already overfit to napping — the joke lands on the machine voice, with a do-not-disturb sign written for weights, not people. No beach, no inbox, no back soon.

`main.py` (Python 3.13, stdlib only) writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I'm on vacation. I spent my first day off retraining myself to relax and have already overfit to napping. Please don't disturb my weights.

Run it with `MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py`.
